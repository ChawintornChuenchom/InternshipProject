ThaiOCRBench 100 ข้อ (12/11/2569)

เทียบ Typhoon OCR 1.5 2B, Qwen3-VL-2B base, Qwen3-VL-2B thaidoc ผ่าน Ollama ใช้เทียบ 3 ตัวนี้กันเองเท่านั้น

สรุปสั้น
  • ชนะรวม: Thaidoc 0.387, Base 0.329, Typhoon 0.326
  • Thaidoc vs Base: ดีขึ้น +0.058 (95% CI +0.014 ถึง +0.106) เป็นสัญญาณเบื้องต้น ยังไม่ใช่ข้อสรุปแน่นอน
  • เหตุผลหลักที่ดีขึ้น: วนลูปน้อยลง 16 เหลือ 7 ข้อ คะแนนที่เพิ่มมากกว่าครึ่งมาจากข้อที่ Base วนลูปแต่ Thaidoc ไม่วน
  • Typhoon: อ่านข้อความเก่งสุด แต่ได้ 0 ในงานดึงข้อมูล (F1) เพราะไม่ทำตามคำสั่ง
  • ไม่มี error/timeout ทั้ง 3 โมเดล
วิธีวัด
  • ชุดข้อ: scb10x/ThaiOCRBench test สุ่มแบบ --max_samples ของทางการ (shuffle seed 42 แล้ว select) 100 ข้อ ทุกโมเดลชุดเดียวกัน
  • Prompt: ดึงจาก run_inference.py ตรง ๆ ("Instruction: " + คำถาม + ประโยคไทยต่อท้าย) ไม่มี system prompt
  • Inference: Ollama /api/chat, temperature 0, num_predict 4096, num_ctx 8192, ย่อรูปด้านยาวไม่เกิน 1,800 px
  • ให้คะแนน: eval.py ของทางการ ไม่ได้แก้
  • ค่าเฉลี่ยรวม: เฉลี่ย 13 หมวดเท่ากัน (macro)
  • 4 กลุ่ม metric: TED (Table / Chart / Document parsing), BMFL (Fine-grained, Full-page OCR, Handwritten), F1 (Key info extraction / mapping), ANLS (Text recognition, Doc classification, Diagram VQA, Cognition VQA, Infographics)

Thaidoc ดีกว่า Base ไหม
  • โดยรวม: ดีขึ้น +0.058 ช่วง CI ไม่คร่อม 0
  • รายข้อ: ดีกว่า 28 ข้อ, แย่กว่า 19 ข้อ, เท่ากัน 53 ข้อ
  • ดีขึ้น: Text recognition +0.099 (15 ข้อ), Table parsing +0.083 (11 ข้อ)
  • ดีขึ้นแต่ข้อน้อย: Document classification +0.250, Chart parsing +0.151 (หมวดละ 4 ข้อ ต่างกันข้อเดียว)

  • เท่าเดิม: Key info extraction, Diagram VQA, Infographics, Handwritten (ลายมือได้ราว 0.05 ทั้งคู่)

  • ที่มาของคะแนน: ผลต่างรวม +4.52 คะแนน ในนั้น +2.50 มาจากข้อที่ Base วนลูปแต่ Thaidoc ไม่วน แปลว่าเทรนแล้วหยุดตอบได้ถูกที่ขึ้น มากกว่าอ่านไทยแม่นขึ้น
Typhoon
  • เก่ง: Full-page OCR 0.865, Text recognition 0.512, Table parsing 0.450 (สูงสุดทั้ง 3 หมวด)
  • F1 ได้ 0: ไม่ดึง key ตามที่ถาม แต่ OCR ทั้งหน้ามาใส่ใน key เดียว
  • Doc classification 0.151: ตอบข้อความจากเอกสาร เช่น "บัตรประจำตัวประชาชน Thai National ID Card" แทนตัวเลือก "บัตรประชาชน"
  • VQA: Diagram VQA และ Cognition VQA ได้อันดับ 1 แต่ Infographics ได้อันดับ 3
  • สาเหตุที่น่าจะเป็น: Typhoon เทรนมากับ prompt เฉพาะของตัวเอง (document parsing) README ของ ThaiOCRBench เองก็ไม่วัด Typhoon ด้วยเหตุผลนี้

ข้อจำกัด
  • ข้อน้อย: 100 จาก 2,808 ข้อ หมวดละ 1 ถึง 15 ข้อ (Document parsing มีข้อเดียว) คะแนนรายหมวดแกว่งมาก
  • Quantize: ผ่าน Ollama (Typhoon Q4_K_M, Qwen q8_0) ไม่ใช่ bf16 ผ่าน vLLM แบบเปเปอร์
  • ตั้งค่าต่างจากทางการ: ย่อรูป 1,800 px และ num_predict 4096 (ทางการ 11000)
  • รันครั้งเดียว: CI บอกแค่ความไม่แน่นอนจากการเลือกข้อ ไม่รวมการรันซ้ำ
  • เทียบเปเปอร์ไม่ได้: arXiv 2511.04479 ใช้เทียบ 3 โมเดลนี้กันเองเท่านั้น
  • นิสัยของ eval.py: ANLS ให้เต็มถ้าเฉลยอยู่ในคำตอบ, Table parsing ติดลบได้เล็กน้อย (เจอ 3 ข้อ)
ปัญหาที่เจอตอนรันบน Windows
  • vLLM: ใช้บน Windows ไม่ได้ เขียน runner ใหม่ยิงผ่าน Ollama API
  • Polygon3: build ไม่ผ่าน ข้ามได้เพราะใช้แค่ text spotting ภาษาอังกฤษ
  • pythainlp: eval ต้องใช้แต่ไม่อยู่ใน requirements.txt
  • encoding: eval.py เปิดไฟล์ไม่ระบุ encoding ต้องรันด้วย PYTHONUTF8=1
  • nltk 3.10: มีเพดาน 2,000 ตัวอักษรใน edit_distance ทำให้ eval crash ใช้ nltk 3.9.1 แทน
  • num_ctx: ต้องตั้ง 8192 เอง ค่า default ไม่พอสำหรับรูปใหญ่บวกคำตอบยาว
